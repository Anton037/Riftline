# Physical sound sources

The shipped WAV contains trimmed, faded and peak-normalized mono excerpts of these CC0 recordings.
The bank is 22,050 Hz / 16-bit PCM; playback and the new physical layers run locally, including offline.
Rebuild: `python tools/build-audio-bank.py` (Python 3 and ffmpeg). Pinned URLs and input hashes are in `tools/audio-sources.json`.
